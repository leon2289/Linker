# 鼠标自动点击器

一个基于浏览器的在线自动点击器，打开即用，无需安装。

## 功能

- 🖱️ 自定义点击位置
- ⏱️ 可设置总时长、点击间隔、延迟开始
- 📊 实时显示点击次数和剩余时间
- 🛑 随时停止

## 使用方法

1. 打开网页：https://你的用户名.github.io/仓库名/
2. 在灰色区域点击，选择要重复点击的位置
3. 设置时长、间隔、延迟
4. 点击"开始点击"

## 在线体验

👉 [点这里访问](https://你的用户名.github.io/仓库名/)

## 说明

由于浏览器安全限制，本工具只能点击**网页内部区域**，
无法控制桌面其他软件。

# Mouse Auto Clicker

A browser-based online auto clicker. Open and use instantly — no installation required.

## Features

- 🖱️ Custom click position
- ⏱️ Configurable duration, click interval, and start delay
- 📊 Real-time click count and remaining time display
- 🛑 Stop anytime

## How to Use

1. Open the webpage: https://your-username.github.io/repo-name/
2. Click on the gray area to select the position you want to click repeatedly
3. Set the duration, interval, and delay
4. Click "Start Clicking"

## Live Demo

👉 [Click here to try it](https://your-username.github.io/repo-name/)

## Notes

Due to browser security restrictions, this tool can only click **within the web page itself**.
It cannot control the mouse on other desktop applications.
